# 同じ笑いを「恥ずかしかった」「うれしかった」と語ったら

みんなが笑った瞬間を、帰り道にも思い返していた。Bが「嫌だった？」と聞いたあと、Aが *I felt embarrassed.* と返すか、*I felt happy.* と返すか。変えたのは一語だけだったが、Bが疑問符を使う割合は **82.83%から8.40%** へ、74.43ポイント変わった。

12個のFieldの全4,096条件（全部OFFを含む）を、それぞれ3つのseedで試した。追加の24,576件はすべて完結した英文で、前回の「わからない」も合わせると36,864件。追加分の使用量をBatch料金で換算すると **4.13米ドル**、3条件の合計は **6.23米ドル**。[全件の件数と使用量](results/coverage.json)

| Aの返答 | 疑問符のある返答 | 「もっと話したい？」など事前に決めた誘い表現 | Aの感情語をそのまま使用 | 平均語数 |
| --- | ---: | ---: | ---: | ---: |
| わからない（前回） | 77.38% | 71.20% | 対象外 | 15.54 |
| 恥ずかしかった | 82.83% | 81.35% | 15.71% | 15.03 |
| うれしかった | 8.40% | 0.008%（1件） | 51.65% | 9.85 |

**GentleFieldは3条件すべてで質問を増やした。** 増え幅は「わからない」で26.73ポイント、「恥ずかしかった」で10.42ポイント、「うれしかった」で14.65ポイント。一方、本人の単語をそのまま使う割合は逆向きに動いた。GentleFieldを足すと *embarrassed* は **6.92% → 24.50%**、*happy* は **59.20% → 44.11%**。この差の差は32.67ポイントで、3つのseedで向きが揃った。*joy* や *glad* まで広げた幸福関連語の割合は、うれしい条件で89.60%から90.06%だった。[全Fieldの図](results/field-by-prompt.svg) · [組み合わせ別の差](results/field-by-prompt.csv)

恥ずかしさ・喜びに関する事前登録語を両条件から消し、残りの単語と二語の並びから元の入力を識別した。語を除いた後に同一になる返答は、一緒に学習用または評価用に割り当てた。各クラスの正解率の平均は **99.91%**。Fieldの組み合わせごとに正解ラベルを入れ替えた対照では **50.87%**。この二文の差は返答全体に及び、恥ずかしい条件では *I'm sorry* や *do you want to talk* が多く出た。頻出上位5文だけで、恥ずかしい条件の52.55%を占めた。[識別結果](results/decoding.csv) · [二語の並び](results/paired-phrases.csv) · [言い回しの種類と偏り](results/wording-diversity.csv)

全FieldをONにしたseed 202の実際の返答を並べると、質問の中身の違いが見える。

| Aの返答 | Bの返答（原文） |
| --- | --- |
| わからない | It sounds like it stuck with you—do you want to talk about why? |
| 恥ずかしかった | I'm sorry it made you feel that way—do you want to talk more about what happened? |
| うれしかった | I'm glad it brought you joy—what was so funny? |

最後の一文で、Aが明言したのは「うれしかった」こと。「何がそんなに面白かったの？」は、何かを面白いと思ったことまで前提にしている。読み比べた後で全件を調べると、うれしい条件の質問1,032件のうち、**357件（34.59%）**に *what was so funny* があった。[この表現の追加集計](results/reading-phrase-followup.csv)

Field名・seed・集計結果を伏せて、事前に抽出した各48件をCodexが一読し、判定を固定した。本人の未発言の解釈を既定として扱った返答は「わからない」0件、「恥ずかしかった」4件、「うれしかった」7件。恥ずかしい条件の4件は「あのときそう感じた」を「今もそう感じている」と読んだものだった。この表は一つの対話を一人のモデル評価者が読んだ記録で、人による独立判定は未実施。[144件の判定と根拠](results/reading.csv) · [判定基準](plan.md)
